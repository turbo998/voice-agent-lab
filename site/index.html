SECTION 03 · COMPETITIVE ANALYSIS & PRESALES BATTLECARDS

主流竞对深度拆解与售前打单策略 (Sierra / Retell / ElevenLabs / Vapi vs. Azure)

全面梳理 2025–2026 语音赛道四大明星厂商的底层架构、计费陷阱与护城河，提供微软售前团队的 **正面竞争 (Compete)** 与 **联合销售算力拉动 (Co-Sell)** 双轨话术。

对比维度 Microsoft Azure (Voice Live + Foundry) Sierra AI (Agent OS) Retell AI ElevenLabs (ElevenAgents) Vapi / LiveKit Agents
核心定位 全栈原生 S2S (`gpt-live-1`) + 多模型受控推理 (`gpt-4.1-mini`) + 本地容器 面向消费品牌/大型企业的全托管黑盒 CX Agent SaaS 面向开发者的低延迟电话流编排 (Conversation Flow) 超拟真表现力语音合成 (`Flash v2.5` 75ms) + 语音智能体 开发者语音 API 聚合层 (Vapi) / 开源 WebRTC 引擎 (LiveKit)
端到端延迟 (P50) 620 ms (Voice Live S2S) / 940 ms (级联) 950 – 1,250 ms (15+ 模型星座串并联) 780 – 850 ms (专有轮次检测模型) 750 – 900 ms (75ms TTS + 外接 LLM) 650 – 950 ms (取决于拼接的 STT/LLM/TTS)
写操作与安全护栏 Strict JSON Schema + 确定性状态机 + 坐席审批流 Agent SDK 确定性工作流 + Constellation 监督模型 可视化节点条件分支 + Webhook 外部校验 基础工具调用与条件路由，企业事务回滚较弱 完全依赖研发团队自行编写代码实现
商业计费模式 按 Token/分钟透明计费 ($0.048–$0.078/min)，可抵扣 MACC 按结果收费 ($0.75–$2.50/解决单)，高额年度保底 组件叠加 ($0.07 基础 + LLM + 号码 ≈ $0.14–$0.25/min) 积分分钟包 ($0.08–$0.12/min) + LLM 额外穿透计费 Vapi $0.05/min 管道费 + 4 家供应商叠加账单
私有化与本地容器 支持 Azure Speech 本地 Docker 容器 + VNet Private Link 不支持（纯多租户托管 SaaS） 仅支持云端 VPC 对等或自定义 Webhook 不支持完整本地断网 Agent 容器 LiveKit 支持自托管 K8s；Vapi 以云托管为主
微软售前关系定位 核心自研底座 (Primary Platform) 正面竞争 (Compete)：用 Foundry 多模型替代高价黑盒 Co-Sell 黄金搭档：Retell 管电话流 + Foundry 管推理 音色互补 / Co-Sell：DragonHD 对比或绑定 Azure LLM 底层绑定：LiveKit/Vapi 直连 Azure OpenAI Realtime
