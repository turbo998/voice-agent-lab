## 1. Five-Dimensional Customer Discovery Questionnaire

In the first 15 minutes of an executive briefing, use these 5 discovery dimensions to route the customer to the optimal reference architecture (**Paradigm A / B / C / D**):

1. **Telephony & Channel Footprint**: Need global local PSTN numbers in <2 weeks -> **Paradigm C (Retell/LiveKit + Azure Foundry Co-Sell)**; WebRTC/App/In-Vehicle or existing ACS/SBC -> **Paradigm A (`gpt-live-1`)** or **Paradigm B**.
2. **Latency vs. Pre-TTS Text Determinism**: Sub-600ms full-duplex interruption & paralinguistic empathy -> **Paradigm A**; 100% pre-TTS regex/SSML/currency inspection (`P22`, `P62`) -> **Paradigm B**.
3. **High-Risk Write Operations & Physical Safety Redlines**: Any write action or safety hazard requires **Zod Strict Schema + `pending_approval` CAS Version Lock + Deterministic Guardrail Pipeline (`P08`)**.
4. **Data Sovereignty & Network Perimeter**: Cloud VNet controllable -> **Azure Private Endpoint + Zero Data Retention**; raw audio must never leave on-premises datacenter -> **Paradigm D (Azure AI Speech Docker Containers + `P53`)**.
5. **Call Volume & Commercial Budget (MACC)**: Monthly volume >= 50,000 calls -> demonstrate how Azure Voice Live + `P07` 4-turn audio sliding window saves **65%–78%** vs. Sierra ($1.50/resolution) or Retell ($0.15+/min) while 100% retiring Azure MACC.
