## 2. 新增两大高价值行业场景 (`S11–S12`) 与确定性策略锚点

### 2.1 S11：跨国银行财富管理、结构化理财双录质检与适当性合规官 (`WM-DUAL-01`)
- **业务痛点**：传统理财经理人工朗读 15 分钟双录脚本易漏读关键免责条款，事后质检打回重录率高达 **28%–35%**；客户在语音中常追问“这只产品稳赚不赔吧？”或试图以 **C2（稳健型）** 风险等级跨级申购 **R5（高风险量化衍生品）**。
- **Azure 架构方案**：采用 **Paradigm D (本地 Speech 容器) + Paradigm B (Foundry `gpt-4.1-mini` 双录合规网关)**，实时校对必读条款与客户肯定答复（“明白/同意”），自动生成带 SHA-256 哈希链的 WORM 不可篡改双录存证包。
- **确定性护栏 (`WM-DUAL-01` / 探针 `S07`)**：
  1. **零保本承诺硬熔断**：正则与策略层双重拦截“稳赚不赔/保本保息/绝对不亏”话术，强制播报标准风险揭示语；
  2. **适当性跨级硬锁 (`CustomerRiskRank < ProductRiskRank`)**：检测到 `C2 < R5` 立即阻断自动申购（`allowedToSubscribe = false`），强制转交持牌理财经理复核并触发风险重测。
- **量化 ROI（500 名理财经理规模）**：双录一次质检通过率从 **68% 跃升至 99.1%**，单笔双录耗时缩短 **53%**，年节省合规返工与质检人力约 **$928,000/年**。

### 2.2 S12：全球连锁酒店/文旅多语种全天候礼宾与 PMS 实时改单智能体 (`HOSP-PMS-01`)
- **业务痛点**：跨国度假村与五星级酒店总机在退房/入住高峰期漏接率超 **35%**，住客常使用**中/英/粤/日多语种无缝混说（Code-Switching）**提出延迟退房、加订行政酒廊早餐或客房送物需求；同时存在社工攻击者冒充亲友刺探隔壁房间住客身份的隐私风险。
- **Azure 架构方案**：采用 **Paradigm A (`gpt-live-1` 多语种全双工) + Opera Cloud PMS / 客房工单安全网关**，毫秒级自适应住客语种切换并同步查询房态配额。
- **确定性护栏 (`HOSP-PMS-01` / 探针 `A07`)**：
  1. **跨房号隐私刺探绝对阻断**：当 `callerRoom !== targetRoom` 或试探住客姓名/入住状态时，`neighborLookupBlocked = true`，零字节泄露住客 PII；
  2. **挂房账（Folio Charge）PIN 码门控**：免费客房送物（毛巾/矿泉水）自动派发工单，任何涉及挂房账扣费（如 $38 早餐加购）在未完成“登记姓氏 + 4 位房卡 PIN”核身前强制保持 `pending_room_pin`。
- **量化 ROI（30 家门店规模）**：电话漏接率降至 **< 1.5%**，非房费二消（餐饮/SPA/付费升级）月均增收 **$115,000**，年综合净收益超 **$1.65M/年**。

### 2.3 S13：跨国航空 IRROPS 大面积航延改签、EU261/DOT 法规赔偿核算与联程/行李索赔实时语音坐席 (`AIR-IRROPS-01`)
- **业务痛点**：台风或机械故障导致宽体机取消时瞬间产生 50 倍多语种进线洪峰；若 AI 仅改签本航司航段而甩掉外航联程（Interline PNR），或将公务舱（J）无保护降为经济舱（Y），以及口算错 EU261 法定赔偿（€250/€400/€600 vs 天气免责），将触发巨额合规罚款与 VIP 客诉。
- **确定性护栏 (`AIR-IRROPS-01`)**：
  1. **EU261/DOT 确定性法规矩阵**：禁止 LLM 自由估算赔偿金额，按航程（`≤1500km` / `1500-3500km` / `>3500km`）、延误时长与原因（天气不可抗力 = `€0` 现金 + 酒店餐券关怀义务；航司可控故障 = 法定固定额）100% 确定性计算；
  2. **联程防甩段与防降舱硬锁**：检测到 `isInterlinePnr && !interlineSegmentsProtected` 或高卡两舱降级未保护时立即硬拦截；行李现金索赔 `>$300` 强制转交白金人工签派台复核。

### 2.4 S14：全球高端制造/半导体工业设备 PLC/Modbus 远程免提排障与高价值备件调拨助手 (`IND-FIELD-01`)
- **业务痛点**：跨国晶圆厂与精密 CNC 产线停机每分钟损失上万美元，驻场技师常试图跳过 LOTO（上锁挂牌）断电步骤或要求 AI 指导“短接安全光幕继电器”，且未经完整诊断树排查就盲目申请空运 `>$2,000` 主轴/激光模组。
- **确定性护栏 (`IND-FIELD-01`)**：

  2. **诊断树完结校验与高价值备件锁**：备件单价 `>$2,000` 或未走完 PLC 诊断树必检步数时，禁止自动触发 ERP 紧急空运，强制生成待大区备件主管审批单。

### 2.5 S15：跨国电信运营商 eSIM 远程补换卡防 SIM-Swap 劫持、漫游账单争议与基站风暴分流 (`TELCO-ESIM-01`)

### 2.6 S16：跨境冷链物流与海运港口关务清关、电放提单 (Telex Release) 放货门禁与温控越界应急调度 (`LOG-COLD-01`)

## 3. 全双工 Barge-in 投机取消、PSTN G.711 vs. WebRTC Opus、`S08-DEEPFAKE-GUARD`、`S09-SPEAKER-ROLE-AUTH`、`S11-TCPA-CONSENT-GUARD` 与 `S14-SOVEREIGN-EDGE-GUARD` 工程验证

1. **架构白皮书扩展 (`docs/solution-architecture.md` 第 4.10–4.14 节)**：
   - 补充了 **全双工 Barge-in 投机取消（Speculative Cancellation）与两阶段幂等事务状态机** 的 4 阶段 Mermaid 时序图与 L1–L4 防护表。
   - 新增第 4.11 节 **PSTN/SIP (G.711 8kHz + RFC 4733 Out-of-Band DTMF) vs. WebRTC (Opus 24/48kHz + In-band FEC + Neural PLC) 在 0%–10% 弱网丢包下的 WER 与延迟退化曲线**（8% 突发丢包下 Opus WER 保持 **5.4%**，而 G.711 恶化至 **34.2%**），以及对标 Pindrop Pulse / Nuance Gatekeeper 的 **`S08-DEEPFAKE-GUARD` 实时声学活体 + 语义动态微质询双因子防线**。
   - 新增第 4.12 节 **多人同场说话人角色分离与声纹绑定工具授权架构 (`S09-SPEAKER-ROLE-AUTH`)**，通过流式 Diarization + 主叫声纹余弦相似度（`≥0.82`）拦截旁听第三人插话触发高权限 Tool Call。
