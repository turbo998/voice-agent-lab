# 从场景咨询到出海服务演练

## 用途与对象

给解决方案架构师、FDE 和中国智能硬件品牌的运营负责人共同使用。
LumaNest 是原创合成品牌，产品、价格、订单、客户和保修说明都仅供演示。
当前交付是部分 Azure 基础、没有云应用运行时；不把演练当真人服务证明。

## 场景假设与咨询结论

品牌准备面向新加坡、马来西亚、泰国客户提供英语浏览器客服，国内运营员
用中文界面处理升级事项。本轮先验证“对话能否安全变成可解释的业务动作”，
不验证电话接通率、真人满意度或跨境个人数据合规。

| 咨询问题 | 本轮明确选择 | 转成实现/验收 |
|---|---|---|
| 客户先需要什么 | 了解产品、查订单、排查配网问题 | 产品目录、身份范围内订单、带来源诊断 |
| 哪些动作必须有人负责 | 工单批准、回访同意 | 固定版本审批、撤回、幂等提交；模型不能代批 |
| 哪些故障不能由语音指导维修 | 烟、火花、过热、电击等 | 停用/安全断电/合格人员处理，不拆机或带电维修 |
| 如何验证而不暴露真人资料 | 三个合成客户与原创知识条目 | 禁止越客户查询；日志/媒体没有凭据与真人资料 |
| 如何使用供应商能力 | Retell 原生流程 + 受限 Foundry 诊断 | 保留原生节点控制，不换自定义 LLM 引擎 |
| 本轮是否接电话 | 否，仅浏览器 | 禁止电话号码采购、拨号、SIP、SMS、充值 |
| 如何比较另一条语音路径 | 独立 GPT Live 实验 | 同业务工具、不同协议/界面，不建立泛化语音框架 |

企业正式咨询还需要负责人确认市场法律、数据留存/跨境路径、售后 SLA、
客服转接方式和真实系统写权限。本实验未取得这些决定，不宣称生产合规。

## 演练前提

Node.js 22+，本仓库依赖与本地构建完成；使用运营登录。
本地默认真实语音门禁关闭、诊断使用明确标注的 fixture。
若服务器实际启用 Foundry，诊断会消费受限推理，不可再称完全离线。
公共证据只使用原创合成数据；麦克风参与和公开人声另需本人明确同意。

## 端到端旅程

1. **咨询。** 英语客户询问 Cam Air 是否适合家用；Agent 披露 AI 和
   合成数据身份，查询目录，不凭想象添加功能、折扣或保证。
2. **查单。** 运营员绑定新加坡客户；输入合成订单 `LN-SG-1001`。
   Agent 不接受口头更换客户权限；其他客户的订单与不存在订单同样拒绝。
3. **诊断。** 客户描述 “My Cam Air cannot pair with my 5 GHz Wi-Fi.”
   诊断引用原创知识条目，解释受支持的 2.4 GHz 路径；未知情况明确升级，
   不把无引用的生成文本当知识证据。
4. **审批。** 工具生成草稿，不创建外部工单。运营员检查优先级、内容与版本，
   批准该版本后才提交；同一动作重试只产生一个合成工单。
5. **同意。** 对合成演练使用明确标注的合成同意证据；真人场景必须运营员
   核实原话/范围/时间。工具返回 `planned_not_dialed`，绝不自动外联系。
6. **撤回。** 撤回审批后不可晚到提交；撤回同意取消相关计划。结束通话不等于
   取消已经开始的业务写入，必须通过业务状态与幂等记录判断结果。

## FDE 定制交接

产品与知识真源位于 `packages/business-core` 和[知识说明](knowledge.md)，
六个输入输出契约位于 `contracts.ts`。更换市场或客户需要同时更新 fixtures、
知识引用、对应测试、运营显示和证据脚本，不能只改系统提示词。
客户身份保持由服务端会话绑定。真实 CRM、物流或退款连接不是本轮范围，
不得把原合成工具直接接真实写权限。

使用 `npm run evidence` 检查六个合成场景，使用 `npm run test:browser`
检查真实浏览器的演练与审批。`npm run test:browser:live` 检查独立云 UI
的双语、草稿与关闭的语音门禁，**没有**供应商调用或真实语音。
供应商阶段再逐项填写[能力证据矩阵](capabilities.md)；模拟通过不能替代该层。
